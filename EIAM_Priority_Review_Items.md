## Suggested order for discussion

1. Group claims vs app roles (Blueprint, DEC-IAM-08 / LLD §6.3) - decides the gateway claims model.
2. Internal-user group vs FAQ groups (Blueprint, DEC-IAM-06) - decides who can obtain a token.
3. Delegated context vs OBO (Blueprint, KG-01) - decides the tool-path delegation pattern.
4. Tools.Invoke grant model (Blueprint, DEC-IAM-20 / LLD EA-08) - decides how the agent is authorised at the tool gateway.
5. Test client type and MFA for test accounts (LLD §6.1/§6.2) - decides the client and test approach.
6. Agent identity claims (LLD §7.1) - decides the policy checks on a real Dev token.
7. Kill-switch role scope and time-to-deny (Blueprint, DEC-IAM-31 / LLD §9.4) - decides the containment lever and target.
8. Terraform plan/apply identity and Graph ownership (LLD §6.3/§9.3) - decides the pipeline privilege model.
